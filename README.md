# 复旦招聘监测台 Fudan Job Watch

自动监测复旦大学官方招聘信源，优先捕获 **外国语言文学学院**、**大学英语教学部** 以及全校教学科研 / 博士后岗位，发现新公告后推送。

## 优先级

- **高-对口**：外文学院 / 大英部的教师、博士后、教学科研招聘
- **中-相关**：全校岗位但涉及语言、翻译、国际交流、区域国别
- **低-其他**：其余教学科研 / 博士后（备查）

通常要求 **博士学历**，线上申报。外文学院联系人郑老师 `fdwwhr@fudan.edu.cn` / `021-65642690`（以最新公告为准）。

## 使用

1. 打开 [GitHub Pages 看板](https://tianshesanlang.github.io/fudan-job-watch/) （启用 Pages 后）
2. 本地打开 `index.html`
3. GitHub Actions 每日 08:00 / 20:00（上海）自动抓取；新出现高优先级岗位会开 Issue
4. 手动跑一次：

```bash
python3 scripts/scrape.py
```
